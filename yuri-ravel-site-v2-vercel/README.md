# Yuri Ravel — V2

Site multipágina, estático e pronto para Vercel.

## Páginas
- `index.html` — Home / visão geral
- `sobre.html` — história e pessoa
- `servicos.html` — serviços e método
- `portfolio.html` — portfólio e laboratório
- `visao.html` — manifesto e princípios
- `contato.html` — contato

## Publicação na Vercel
1. Suba todos os arquivos mantendo a pasta `assets/`.
2. Importe o repositório na Vercel.
3. Framework Preset: Other.
4. Build Command: vazio.
5. Output Directory: `.`
